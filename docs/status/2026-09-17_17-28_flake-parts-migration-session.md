## e) WHAT WE SHOULD IMPROVE

1. **"Reference-first" rule for structural migrations.** When a working sibling repo has the exact pattern, the first draft should be its verbatim shape; divergences come after a green gate, one at a time, each with evidence. Impact: eliminates the entire class of d1. Suggested fix: add one line to AGENTS.md working rules (Mig lesson: "copy the reference shape first, verify, then deviate").
2. **Fast-eval guard immediately after every flake-structure write.** The two `nix eval` guards (x86_64 attrNames, aarch64 shape) cost seconds and would have caught d1 before the daemon committed it. Make it reflexive: write → eval guards → only then docs.
3. **Mechanize the compat doctrine (c3/c5).** AGENTS.md rules that only exist in prose get violated by well-meaning future sessions. SystemNix already demonstrates the eval-guard pattern (`builtins.seq` + `assert ... || throw`); nix-email should have the same two guards (nixpkgs-rev parity with SystemNix, nixpkgs-lib follows).
4. **Decisions get recorded at decision time, not report time.** The treefmt/systems/git-hooks rejections (c6) were made live and would silently re-litigate in a future session. Three AGENTS.md lines prevent that.
5. **Session-level: verify push/CI state before ending.** I ended the session without checking that the daemon hadn't pushed a broken intermediate (it hadn't — confirmed only now during this report). A 5-second `git status -sb` + `gh run list` belongs in the wrap-up.
